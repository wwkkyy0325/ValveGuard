## Model runtime

```bash
pip install -r requirements-onnx.txt
```

```python
from valveguard.models.onnx_artifact import load_onnx_detector

detector = load_onnx_detector("valveguard_cnn_v1_onnx")
scores = detector.score_channels(channels, names)
players = detector.aggregate(frame, scores)
```

`load_onnx_detector` does not import torch. The bundle manifest records
SHA256 checksums for every file and the loader rejects mismatches.

## Publishing on GitHub

Git and Releases have different jobs:

- **Git**: source, configs, manifests, checksums, docs, and README links.
- **Releases**: large binaries. Release assets do not bloat the git clone.

The release is built by `.github/workflows/release.yml` on a Windows runner.

### One-time model asset

The ONNX bundle is not committed. Do one of these once:

1. Create a release with tag `model-v1` and attach
   `artifacts/valveguard_cnn_v1_onnx.zip`; or
2. Set the repository variable `VALVEGUARD_MODEL_URL` to any URL that serves
   that zip.

Optionally set `VALVEGUARD_MODEL_SHA256` to the expected lowercase SHA256;
the workflow then rejects a mismatched download.

### Cut a release

```bash
git tag v1.0.0
git push origin v1.0.0
```

Or run Actions -> Release -> Run workflow, enter the tag, and optionally
override the model URL for that run.

The workflow:

1. downloads and optionally verifies the ONNX bundle;
2. runs `npm run tauri build -- --bundles nsis,msi`;
3. builds `valveguard-desktop-v1-win64.zip` (`ValveGuard.exe` + `model/`);
4. writes `SHA256SUMS.txt`;
5. creates the GitHub Release with the portable zip, the model zip, the
   NSIS installer, the MSI installer, and the checksums.

Stable URLs:

```text
https://github.com/wwkkyy0325/ValveGuard/releases/latest
https://github.com/wwkkyy0325/ValveGuard/releases/download/v1.0.0/valveguard_cnn_v1_onnx.zip
https://github.com/wwkkyy0325/ValveGuard/releases/download/v1.0.0/valveguard-desktop-v1-win64.zip
```

Manual fallback, if Actions is unavailable:

```bash
gh release create v1.0.0 \
  artifacts/valveguard_cnn_v1_onnx.zip \
  artifacts/valveguard-desktop-v1-win64.zip \
  --title "ValveGuard v1.0.0" \
  --notes-file docs/releases/v1.0.0.md
```

## Why not commit the binaries

- The model zip is 28 MB. Git stores every version of a committed binary
  forever; release assets do not enter the clone.
- The model is reproducible from the local artifact bundle with
  `export_onnx.py`, and the manifest carries checksums.
- If the model must live in git, use Git LFS for `*.onnx` and zip files,
  not a normal commit. Releases remain the simpler distribution path.
