# ValveGuard v1.0.1

Installer-focused release. The app and model behaviour are unchanged from
v1.0.0.

## Changes

- NSIS installer is per-user with SimpChinese and English languages.
- Uninstall now asks whether to delete the analysis history in
  `Documents/ValveGuard`. Choosing No keeps the records.
- Silent uninstall keeps records by default; `/DELETEUSERDATA` removes them
  for unattended cleanup.
- Full cleanup also removes `%LOCALAPPDATA%\com.valveguard.review`.
- Reinstalling or upgrading shows the maintenance page. Upgrades default to
  uninstall-before-install; that uninstall keeps the records without asking.
- MSI and portable zip are still published. The MSI does not touch
  `Documents/ValveGuard`; the portable zip has no uninstaller.

## If setup cannot write `modern-wizard.bmp`

The error points at `%TEMP%\nsn*.tmp\modern-wizard.bmp`, which is the NSIS
wizard's cosmetic image, not a ValveGuard file.

- Click Retry, or Ignore to skip that image and continue.
- Clear stale `%TEMP%\nsn*.tmp` folders and make sure the disk is not full.
- Check antivirus/EDR blocking writes under `%TEMP%`.
- Use the MSI or the portable zip instead.
