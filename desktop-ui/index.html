    怎么读结果

    每位玩家有一组 256 tick 的击杀窗口分数；用 k0=5 向人类先验收缩后得到风险分。风险分 ≥ p99 判为 FLAG，p95–p99 为 REVIEW。行为理由只调整复核顺序，不改变分数。

    使用边界

    研究用复核工具，不用于自动封禁、实时对局或任何在线执法。证据不足的玩家会被保留在名单里，但不应据此采取行动。
